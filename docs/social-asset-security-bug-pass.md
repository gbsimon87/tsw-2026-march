# Social asset backlog ranks 1–10: security and bug pass

Reviewed the export presets, player and milestone cards, caption and attribution
builders, game kit and carousel, league leader cards, consent resolution, and
highlight receipt against the rank 1–10 definitions in `ideas.md`. This log
records reproducible defects and the corresponding fix. Public Pulse posts are
ordinary public game content; this pass concerns the marketing export and
Instagram hand-off surfaces.

SA-01 to SA-05 came from the first pass over the consent and download paths.
SA-06 onward came from a second pass that added a dedicated security review and
per-rank correctness reviews; every row below was reproduced against the code at
the cited line before being recorded. Nothing in this file is fixed yet.
