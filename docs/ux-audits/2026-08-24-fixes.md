## Friction

- Admin tab no longer resets; `Track a game` is on the team row itself, so the
  core action is one click from `/admin` instead of three.
- `Add player` focuses the new row's name field.
- Create Team is one required field plus an optional roster; logo, colours and a
  full postal address moved behind one disclosure (1,300px → ~490px).
  Create Game did the same with schedule, format and video (1,100px → ~610px).
- `No Assist` / `Dismiss` became `Unassisted` / `Skip this question`.
- The Add Event dialog hugs its content: ~450px of dead space gone on desktop,
  and on mobile the actions moved out of the screen's bottom edge into the
  thumb zone (844px panel → ~460px, centred).
- `/pricing`'s free column sends a signed-in visitor to `/admin`, which is what
  its own copy promises, instead of to the feed.

## Visual system

- **One page surface.** The `bg-[#F7F5F0] -m-4 p-4 md:-m-6 md:p-6` hack was
  copy-pasted across 14 pages and ended at content height, leaving a hard colour
  seam and dead grey below the footer; pages that omitted it got a different
  background entirely. The shell now owns the surface and grows to fill the
  viewport. 14 copies deleted.
- **Four colours, not eleven.** The tracker's event picker used seven unrelated
  hues; the rest of the tracker added sky, emerald, rose and indigo on top. All
  of it now maps to ink `#141414`, forest `#1B4332`, amber `#F4A300` and red
  `#B42318` — points scored / possession lost / neutral stat / attention. Every
  pair was measured; the lowest is 6.49:1. The old rebound amber was the one
  genuine AA failure at 3.19:1.
- **One tab pattern.** The active tab was a square-cornered black block
  overhanging a rounded card. It is now a pill inside the card's padding, with
  `role="tablist"` and `aria-selected` on Admin (which had neither).
- **Controls look alike.** `formStyles.js` is the single definition of an input;
  it replaced four different treatments, an unstyled file input, unstyled
  selects, and a bordered `<fieldset>` with an inset legend that appeared once
  in the whole app.
- **Colour slots read honestly.** An unset team colour rendered as a solid black
  bar labelled "Not set"; it is now a hatched empty swatch.
- **One player avatar.** `player-placeholder.svg` was sky `#0ea5e9` while the
  team placeholder was amber, so the same person changed colour between
  surfaces. Now ink + amber.
- **Titles stop truncating.** `DarkPageHeader` ellipsised the page's own
  identity on mobile ("Metro Spring Le…").
- **Standings.** Team names on one line, `Record` header matching its 3-part
  values, permanent underlines removed, and a scroll cue so PF/PA/+− read as
  "more to the right" rather than a clipped table.
- **Browser surfaces themed** — selection, caret, focus ring, scrollbar, and
  tabular numerals for every table and score.

## A real bug the audit surfaced by accident

`GameStatsCharts` multiplied `percentage` by 100, but `statSummary.js` already
returns 0–100. A 1-for-1 three-point night plotted as **10000%** and dragged the
y-axis domain to `[0, 10000]` — which is why the axis labels looked truncated
(`000%`, `500%`). The tiles beside the chart used a different formatter and were
correct, so the two disagreed on the same screen. Fixed in
`GameStatsCharts.jsx`; the negative `left: -20` chart margin that made it worse
is gone too.

## Motion (transitions-dev)

Every state change in the app was instant. Added, with the snippets' own
`prefers-reduced-motion` guards and the universal `:root` block installed once:

| Transition         | Where                                                                |
| ------------------ | -------------------------------------------------------------------- |
| Modal open / close | `Modal.jsx` (all confirms), tracker event picker                     |
| Panel reveal       | tab panels (Admin, recap, tracker), form disclosures, consent banner |
| Number pop-in      | live scores, per changed digit only                                  |
| Success check      | "team is ready" confirmation                                         |
| Error state shake  | auth form on failed submit                                           |

The full value of the score pop-in stays in the DOM as real text
(`sr-only`), so screen readers, DOM queries and copy-paste see `24`, not two
glyph nodes.

## Chart palette (dataviz)

Away series was `#38bdf8`, which fails contrast against the chart surface at
2.09:1. The replacement pair was chosen by running the skill's validator rather
than by eye:

```
validate_palette.js "#C77F00,#1F6FB2" --mode light
  PASS lightness band · PASS chroma floor
  PASS CVD separation (protan ΔE 24.2 · tritan 25.8)
  PASS normal-vision floor (29.9) · PASS contrast vs surface
```

Slot order is fixed — home is always slot 1 — so filtering never repaints the
other series.

## Two audit claims corrected

Both were written from screenshots and disproved by measurement:

1. "Several event-picker buttons fail WCAG AA." Only the rebound amber did
   (3.19:1). The others pass; the defect was incoherence, not contrast.
2. "Mobile standings drop PF, PA and differential." They render — they were
   scrolled off-screen with no cue.
